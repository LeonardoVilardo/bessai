# BESSAi Web Dashboard

This folder contains the Next.js frontend for BESSAi.

Use the root project README for setup, local development, and deployment instructions:

[../../README.md](../../README.md)

Key files:

- `src/app/page.tsx`: dashboard UI and client-side API calls.
- `src/data/default-demo-result.json`: bundled Brasilia demo result.
- `src/data/west-bahia-demo-result.json`: bundled West of Bahia farm demo result.
